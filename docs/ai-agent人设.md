# AI 驱动的自动化创业孵化系统 (AISA) - 深度优化指南

## 0. 项目背景与目标

当前项目已初步实现 AI 辩论与分发功能。本次优化的目标是：**提升话题的前沿性、增强辩论的对抗深度、实现多模型能力互补、并优化多平台分发质量。**

## 1. 输入层优化：扩展“灵感捕获”矩阵

**现状审计：** 审查 `data_ingestion/` 或类似模块。

**优化要求：**

- **接入多维数据源：** 增加对以下渠道的 API 或爬虫支持：
  - **arXiv (AI 论文):** 捕捉最新的 AI 应用趋势。
  - **Product Hunt:** 监控全球新上线的产品方向。
  - **小红书/Reddit:** 抓取带有“避雷”、“痛点”、“求助”标签的热帖，发现真实需求。
- **智能化预筛选：** 引入 **Gemini 3 Flash** 作为“信息漏斗”，通过特定 Prompt 过滤掉同质化严重的点子，仅保留具有“高商业价值”或“技术突破性”的原始话题。

## 2. 角色层优化：多模型 Agent 差异化配置

**优化要求：** 修改 `agent_manager.py`，实现不同任务与最强适配模型的精准绑定。

| **角色名称**               | **推荐模型**             | **核心优化指令 (System Prompt 方向)**                        |
| -------------------------- | ------------------------ | ------------------------------------------------------------ |
| **硬核技术派 (The Tech)**  | **GPT-o1 / DeepSeek-R1** | 侧重：系统架构拆解、研发成本评估、技术护城河挖掘。必须指出技术实现上的“坑”。 |
| **市场毒舌派 (The VC)**    | **Claude 3.5 Sonnet**    | 侧重：商业闭环、LTV/CAC 测算、市场空间、退出机制。必须以批判性视角质疑盈利能力。 |
| **落地执行官 (The PM)**    | **Qwen-Max (通义千问)**  | 侧重：中国本土化落地、私域运营、供应链对接。提供具体到第一周该做什么的 SOP。 |
| **首席裁判官 (The Judge)** | **Gemini 3 Flash**       | 侧重：逻辑一致性检查、冲突调解、综合评分（1-10分）。负责生成最终的决策报告。 |

## 3. 逻辑层优化：引入“对抗式”辩论循环

**优化要求：** 重构 `debate_engine.py` 逻辑。

- **强制红蓝对抗：** 辩论过程不能轻易达成共识。要求 VC Agent 必须提出至少 3 个“致命风险”，Tech/PM Agent 必须针对性给出“避坑方案”。
- **极端约束测试：** 在第二轮辩论中自动注入限制条件（例如：“如果初期预算只有 5 万人民币且不准买流量，该如何起步？”）。
- **逻辑闭环验证：** 裁判模型需判断辩论是否充分，未达标则自动触发补充回合。

## 4. 输出层优化：多平台内容差异化分发

**优化要求：** 增强 `distribution/` 模块的文案生成能力。

- **飞书/钉钉通知：** 生成《决策快报》，包含：评分、核心风险、推荐级别。
- **微信公众号：** 使用 Claude 3.5 生成深度行业分析长文，包含行业趋势、技术架构图描述、商业模式分析。
- **小红书/短视频：** 切换至 **GPT-4o**，生成爆款标题、Emoji 风格文案，并输出高审美水平的 AI 生图提示词 (Stable Diffusion/Midjourney)。

## 5. 请 Windsurf 立即执行的任务

1. **代码库审计：** 扫描项目目录，识别负责模型调用、工作流管理、数据存储及分发的具体文件。
2. **配置文件重构：** 统一创建一个 `config/model_settings.yaml`，集中管理各角色的 Model ID、Temperature 及 API Keys。
3. **辩论引擎升级：** 针对 `debate_engine` 模块，提出一套支持“多轮对抗博弈”的代码重构方案（优先考虑使用异步调用提高性能）。
4. **Prompt 库隔离：** 将所有 Agent 的 System Prompt 抽离到独立的 `prompts/` 文件夹中，方便后期针对不同行业进行微调。
